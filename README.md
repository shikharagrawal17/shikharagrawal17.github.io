## 🚀 Step-by-Step GitHub Pages Deployment Guide

Follow these simple steps to deploy your portfolio to GitHub Pages:

### Step 1: Initialize Git Repository
In your terminal, navigate to the portfolio folder and initialize git:

```bash
cd /Users/shikhar/.gemini/antigravity-ide/scratch/shikhar-portfolio
git init
git add .
git commit -m "feat: initial commit for Shikhar Agarwal developer portfolio"
```

### Step 2: Create a New GitHub Repository
1. Go to [GitHub.com](https://github.com/new) and create a new repository (e.g., `shikhar-portfolio` or `shikharagrawal17.github.io`).
2. Link your local repository to GitHub:

```bash
git branch -M main
git remote add origin https://github.com/shikharagrawal17/<repository-name>.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (top navigation tab) ➔ **Pages** (left sidebar under 'Code and automation').
3. Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
4. Set Branch to `main` and Folder to `/ (root)`.
5. Click **Save**.

Within 1-2 minutes, your website will be live at:
`https://shikharagrawal17.github.io/<repository-name>/` (or `https://shikharagrawal17.github.io/` if using the user page repo).
